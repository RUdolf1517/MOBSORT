# Mobilization Sort

Небольшая шуточная TUI-утилита на Rust: случайные элементы призываются волнами, сортируются внутри отряда и возвращаются в общую отсортированную формацию. Визуализация построена на Ratatui/Crossterm; музыка синтезируется через CPAL.

## Как работает алгоритм

Алгоритм хранит два набора: **резерв** (ещё не обработанные элементы) и **формацию** (уже отсортированные элементы). Проценты волн трактуются как накопленное покрытие исходного массива: 10%, 25%, 50%, 75%, 100%. Цель каждой волны округляется вверх; волна выбирает случайные новые элементы до достижения этой цели. Если у небольшого массива соседние цели округлились в одинаковое количество, пустая волна пропускается.

На каждой волне мобилизованная группа сортируется пошаговой стабильной сортировкой слиянием, затем пошагово сливается с уже отсортированной формацией. Вся группа действительно изымается из резерва; ни полный отсортированный массив заранее, ни подмена результата не используются.

**Корректность.** Инвариант перед каждой волной: формация отсортирована и содержит все ранее мобилизованные элементы; резерв содержит остальные. Отряд из резерва сортируется, после чего слияние двух отсортированных последовательностей снова даёт отсортированную формацию. Каждая непустая волна увеличивает её размер. Цель пятой волны равна размеру исходного массива, поэтому в конце резерв пуст, а формация содержит все значения в порядке возрастания. Сравнение по паре `(значение, исходный индекс)` корректно обрабатывает отрицательные и повторяющиеся числа.

Например, для 50 элементов размеры новых отрядов — 5, 8, 12, 13 и 12: после волн формация содержит 5, 13, 25, 38 и 50 элементов соответственно.

## Запуск

Требуется стабильный Rust toolchain.

```sh
cargo run --release
```

Для сборки без аудиовыхода:

```sh
cargo run --release --no-default-features
```

На Linux с включённым звуком могут понадобиться системные ALSA-заголовки (например, пакет `libasound2-dev` в Debian/Ubuntu). Отсутствие аудиоустройства не мешает пользоваться сортировкой: TUI продолжит работу без звука.

## Источники данных

- **Random** — по умолчанию 50 чисел в диапазоне 1…100; количество и границы можно изменить.
- **Manual** — целые числа, разделённые пробелами, запятыми или `;`.
- **File** — числовой TXT/CSV; разделители — пробел, запятая или `;`, комментарии после `#` игнорируются.

Поддерживаются значения `i64`, включая отрицательные; ограничение интерфейса — 3000 элементов.

## Управление

| Клавиша | Действие |
|---|---|
| `↑` / `↓`, `Enter` | Выбор источника / подтверждение |
| `Space` | Пауза / продолжение |
| `R` | Перезапуск с тем же входным массивом |
| `M` | Выключить / включить музыку |
| `[` / `]` | Уменьшить / увеличить громкость |
| `+` / `-` | Ускорить / замедлить анимацию |
| `←` / `→`, `PageUp` / `PageDown` | Горизонтальная прокрутка столбиков |
| `Esc` | Вернуться в меню |
| `Q` | Выход |

Визуализация использует общую нулевую линию для положительных и отрицательных чисел, автоматически масштабирует высоты и прокручивает большие массивы по горизонтали. Цвета формации, отряда и резерва различаются; текущий перемещаемый элемент подсвечивается.

Звуковая последовательность одна на весь запуск и не сбрасывается между волнами. Ноты следуют за набором и возвращением элементов, а темп адаптируется к размеру массива. По окончании последовательность продолжается с начала; `M` отключает звук.

## Зависимости

Прямые зависимости Cargo: `ratatui`, `crossterm`, `rand` и необязательная feature `audio` на базе `cpal`. Ввод TXT/CSV, конфигурация, ошибки и синтез мелодии не требуют дополнительных библиотек. Можно собрать без `cpal` через `--no-default-features`.

## Релиз и Homebrew

GitHub Actions workflow `.github/workflows/release.yml` собирает Windows x86_64 `.exe` и архивы macOS для Intel и Apple Silicon. При публикации GitHub Release с тегом `v*` workflow прикладывает бинарные файлы и `SHA256SUMS.txt` к этому релизу.

Формула находится в `Formula/mobilization-sort.rb`. После публикации репозитория с этой формулой добавить его как tap можно так:

```sh
brew tap RUdolf1517/MOBSORT https://github.com/RUdolf1517/MOBSORT.git
brew install mobilization-sort
```

Формула собирает программу из версии-тега с помощью Rust, поэтому для Homebrew не нужен отдельный tap-репозиторий.
