# Mobilization Sort

Интерактивная консольная реализация поэтапной сортировки целочисленного массива. Программа иллюстрирует формирование отсортированной последовательности из случайно выбранных групп и отображает основные переходы алгоритма.

## 1. Назначение и модель данных

Пусть входной массив содержит $n$ целочисленных значений
$A=(a_0,\ldots,a_{n-1})$. Элементу исходной позиции $i$ сопоставляется пара
$(a_i,i)$. Параметр $i$ является уникальным идентификатором элемента; сравнение
выполняется лексикографически по значению, а затем по идентификатору. Поэтому
повторяющиеся значения получают однозначный и устойчивый порядок.

На границах волн массив разбит на две логические части:

- **формация** $F$ — уже собранные элементы в отсортированном порядке;
- **резерв** $R$ — ещё не набранные элементы.

Во время волны выбранная группа $B$ временно отображается как мобилизованный
отряд, сортируется и затем включается в формацию. В начале $F_0=\varnothing$,
а $R_0$ содержит все элементы исходного массива. Между завершёнными волнами
формация и резерв образуют непересекающееся разбиение исходных элементов. В
конце алгоритма резерв пуст, а формация содержит каждый входной элемент ровно
один раз.

## 2. Алгоритм

Используются пять кумулятивных целевых долей входа:

$$
(p_1,p_2,p_3,p_4,p_5)=(10,25,50,75,100)\%.
$$

Целевой размер формации после волны $j$ равен

$$
t_j=\min\left(n,\left\lceil\frac{p_j n}{100}\right\rceil\right).
$$

Если перед волной формация содержит $|F_{j-1}|$ элементов, число новых
элементов для набора определяется как

$$
m_j=\max\left(0,t_j-|F_{j-1}|\right).
$$

В каждой волне выполняются следующие операции:

1. Формируется список позиций, содержащих элементы текущего резерва. Список
   перемешивается генератором случайных чисел, после чего выбираются первые
   $m_j$ позиций. Выборка выполняется без возвращения и является псевдослучайной;
   параметр фиксированного seed не предоставляется.
2. Выбранная группа сортируется инкрементальной стабильной сортировкой слиянием.
3. Отсортированная группа сливается с текущей формацией.
4. После завершения слияния проверяются размер формации, её упорядоченность,
   отсутствие потерь и повторов относительно резерва.

Для входа из 50 элементов целевые размеры формации и размеры новых групп имеют
вид:

| Волна | Целевая доля | Целевой размер $t_j$ | Новый набор $m_j$ |
|---:|---:|---:|---:|
| 1 | 10% | 5 | 5 |
| 2 | 25% | 13 | 8 |
| 3 | 50% | 25 | 12 |
| 4 | 75% | 38 | 13 |
| 5 | 100% | 50 | 12 |

Округление вверх может привести к совпадающим целевым размерам на соседних
уровнях для малых массивов. Такие пустые волны пропускаются. Пустой вход
завершается без набора; singleton обрабатывается одной непустой волной.

## 3. Корректность и вычислительная сложность

После каждой завершённой непустой волны формация отсортирована по ключу
$(a_i,i)$. Совместно резерв и формация содержат все исходные пары ровно по
одному разу. Сортировка группы сохраняет соответствие идентификаторов исходным
значениям, а слияние двух упорядоченных последовательностей даёт упорядоченную
формацию. В конце пятой целевой волны $t_5=n$, поэтому резерв пуст и результат
содержит весь вход.

На каждой волне выбор состава группы требует не более $O(n)$ операций; число
волн ограничено константой пять. Сортировки групп суммарно требуют $O(n\log n)$
операций в худшем случае, а слияния — $O(n)$ с точностью до постоянного
множителя числа волн. Итоговая временная сложность равна $O(n\log n)$,
дополнительная память — $O(n)$. Сортировка и слияние выполняются инкрементально;
инварианты проверяются после каждой волны. Такое устройство позволяет отображать
промежуточные перемещения элементов.

## 4. Входные данные

В меню доступны три источника массива:

| Источник | Параметры и формат |
|---|---|
| **Random** | Количество элементов (0–3000) и включительные границы диапазона. Значения по умолчанию: 50 элементов из диапазона $[1,100]$. |
| **Manual** | Целые числа, разделённые пробелами, запятыми или точками с запятой. |
| **File** | Путь к текстовому файлу TXT/CSV; используются те же разделители, что и для ручного ввода. |

Тип значений — `i64`; максимальная длина массива — 3000 элементов. Отрицательные
и повторяющиеся числа поддерживаются. В TXT/CSV-файлах часть строки после `#`
считается комментарием. Например:

```text
-8, 0; 14
3 11 # комментарий после данных
```

Пустой ввод или пустой файл задаёт пустой массив. Для генерации случайного
массива минимум не должен превышать максимум; обе границы включаются в диапазон.

## 5. Визуализация и звуковая индикация

Экран сортировки содержит три области: отсортированную формацию,
мобилизованный отряд текущей волны и резерв. Цвета областей — зелёный, жёлтый и
голубой соответственно. Перемещаемый элемент кратко выделяется красным, затем
принимает цвет области, в которую он перешёл. Высота столбца задаётся значением
элемента на общей для слоёв шкале с нулевой базовой линией.

По умолчанию обзорный режим подбирает число экранных столбцов по доступной
ширине области графика. Если отдельный столбец можно выделить каждой позиции,
агрегация не требуется. При нехватке ширины соседние позиции объединяются в
группы. Для каждой группы графически отображаются её минимальное и максимальное
значения; промежуточные значения отдельно не кодируются. Подпись сообщает
приблизительное число позиций, приходящихся на один экранный столбец. В резерве
это число может включать позиции, уже освобождённые после набора элементов.
Клавиша `D` включает детальный режим с отдельными столбцами и подписями значений;
стрелки прокручивают его на три позиции, а `PageUp`/`PageDown` — на двенадцать.
Клавиша `F` возвращает обзор всего массива. Изменение размера терминала
пересчитывает масштаб.

Звуковая последовательность основана на 102-нотной транскрипции партии
первого корнета из симфонической партитуры, транспонированной в звучащий до
мажор. Темп последовательности — 76 BPM; звук синтезируется программно с
многоголосным медным тембром и коротким пространственным хвостом.

**Нота запускается только событием набора нового элемента из резерва в отряд.**
Сортировка, слияние, ожидание и запуск приложения сами по себе нот не запускают.
Фоновое или отложенное проигрывание отсутствует. Клавиша `M` отключает звук;
при недоступном аудиоустройстве программа сохраняет функции сортировки и
визуализации.

## 6. Управление

| Клавиша | Действие |
|---|---|
| `↑` / `↓` | Выбор источника массива в меню |
| `Enter` | В меню — открыть форму выбранного источника; в Random — перейти к следующему полю или запустить; в Manual/File — запустить |
| `Tab` | Следующее поле формы |
| `Backspace` | Удаление последнего символа активного поля |
| Печатные символы | Ввод в активное поле формы |
| `Space` | Приостановка или продолжение сортировки |
| `R` | Повторный запуск на том же массиве (во время сортировки или на экране итогов) |
| `M` | Отключение или включение звука (в меню, во время сортировки или на экране итогов) |
| `[` / `]` | Уменьшение или увеличение громкости во время сортировки или на экране итогов |
| `+` / `-` | Изменение скорости анимации во время сортировки |
| `F` | Во время сортировки или на экране итогов — обзорный масштаб, весь массив |
| `D` | Во время сортировки или на экране итогов — детальный масштаб с подписями |
| `←` / `→`, `PageUp` / `PageDown` | В детальном режиме сортировки или итогов — горизонтальная прокрутка на 3 или 12 позиций соответственно |
| `Esc` | Возврат в меню с экрана сортировки/итогов; в форме — отмена ввода |
| `Q` | Завершение программы вне формы ввода |

## 7. Сборка, тестирование и системные зависимости

Для сборки требуется стабильный набор инструментов Rust (rustc и Cargo).
Текстовый интерфейс терминала использует `ratatui` 0.28 и `crossterm` 0.28;
`rand` 0.8 обеспечивает генерацию случайных массивов и выбор элементов.
`cpal` 0.15 подключается необязательной Cargo feature `audio`, включённой по умолчанию.
Из корневого каталога проекта запустите:

```sh
cargo run --release
```

Чтобы собрать и запустить программу без звуковой подсистемы:

```sh
cargo run --release --no-default-features
```

Тесты и проверка форматирования:

```sh
cargo test --no-default-features
cargo fmt --all -- --check
```

На Linux для аудиосборки могут потребоваться `pkg-config` и заголовки ALSA.
Например, в Debian/Ubuntu это пакеты `pkg-config` и `libasound2-dev`; в Fedora —
`pkgconf-pkg-config` и `alsa-lib-devel`. Сборка с `--no-default-features` не
подключает CPAL. Форматирование терминала должно поддерживать не менее 36
столбцов и 18 строк; при меньшем размере приложение выводит требование увеличить
окно.

## 8. Установка готовых сборок

[Релиз v0.1.2](https://github.com/RUdolf1517/MOBSORT/releases/tag/v0.1.2)
содержит следующие артефакты:

- Windows x86_64: `mobilization-sort-windows-x86_64.exe`;
- macOS Intel: `mobilization-sort-macos-x86_64-apple-darwin.tar.gz`;
- macOS Apple Silicon: `mobilization-sort-macos-aarch64-apple-darwin.tar.gz`;
- SHA-256 контрольные суммы: `SHA256SUMS.txt`.

В Windows запустите загруженный файл `.exe`. Для macOS распакуйте архив,
соответствующий архитектуре компьютера, например:

```sh
tar -xzf mobilization-sort-macos-aarch64-apple-darwin.tar.gz
./mobilization-sort
```

Для проверки контрольных сумм на macOS используйте
`shasum -a 256 -c SHA256SUMS.txt`, на Linux — `sha256sum -c SHA256SUMS.txt`.
В Windows PowerShell вычислите сумму исполняемого файла командой
`Get-FileHash .\mobilization-sort-windows-x86_64.exe -Algorithm SHA256` и
сравните её с записью в `SHA256SUMS.txt`.

Linux-бинарник в этом релизе не публикуется; на Linux программу можно собрать из
исходного кода командами из предыдущего раздела.

## 9. Установка и обновление через Homebrew

Формула находится в `Formula/mobilization-sort.rb` в tap
`RUdolf1517/MOBSORT`. Первичное подключение tap и установка:

```sh
brew tap RUdolf1517/MOBSORT https://github.com/RUdolf1517/MOBSORT.git
brew install mobilization-sort
```

Для обновления формулы и установленной версии:

```sh
brew update
brew upgrade rudolf1517/mobsort/mobilization-sort
```

Формула собирает приложение из исходного кода и требует Rust. Для обновления
Homebrew сначала синхронизирует локальную копию tap; опубликованный GitHub Release
сам по себе не обновляет локальный индекс формул.

## 10. Ограничения и диагностика

- Вход ограничен 3000 целыми значениями типа `i64`.
- Случайная выборка волн не воспроизводится по фиксированному seed.
- В обзорном масштабе группы элементов свёрнуты в диапазоны; для просмотра
  отдельных значений используйте `D` или клавиши прокрутки.
- При отсутствии аудиоустройства сортировка выполняется без звука.
- Для аудиосборки на Linux проверьте наличие системных библиотек ALSA; при их
  отсутствии используйте сборку с `--no-default-features`.
